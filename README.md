# 📋 FieldOps

Sistema de gerenciamento de **inspeções técnicas em campo**, com foco em organização, segurança e rastreabilidade.

## 🎯 Objetivo

Permitir **planejar, executar, acompanhar e revisar inspeções**, inclusive offline.

## 🧩 Sistema

* 📱 **Mobile:** execução de inspeções, checklist, fotos, QR Code, localização e modo offline.
* 💻 **Web:** usuários, equipamentos, modelos, agendamento, acompanhamento e aprovação.
* ⚙️ **API:** regras de negócio, autenticação, dados e sincronização.

## 🛠️ Tecnologias

**React Native • Expo • Angular • TypeScript • Java • Spring Boot • PostgreSQL • SQLite**

## 🔄 Fluxo

**Criar modelo → Agendar → Atribuir → Executar → Sincronizar → Revisar → Aprovar/Reprovar**

## 👥 Perfis

* **Administrador:** configura o sistema.
* **Supervisor:** planeja e revisa inspeções.
* **Técnico:** executa inspeções em campo.

## 📦 MVP

O MVP contempla **cadastro, criação de inspeções, execução de checklist, QR Code, evidências, funcionamento offline, sincronização e aprovação**.
