# FieldOps React Native

Conversão da aplicação web para React Native usando Expo + TypeScript.

## Rodar

```bash
npm install
npm start
```

O projeto usa Expo SDK 57. Para desenvolvimento local, execute `npm start`; para Android/iOS, use um development build/EAS ou um ambiente nativo configurado.

## Dados

Esta versão é um protótipo somente para visualização. Todos os dados são locais/mock e não há autenticação, banco de dados, persistência ou chamadas de API.

## Estrutura

- `App.tsx`: shell do app, tema, busca e estado global simples.
- `src/screens/`: cada tela em arquivo separado.
- `src/components/`: menu, cards, badges e gráficos.
- `src/data/`: dados de demonstração.
- `src/types/`: tipos TypeScript.
- `src/theme/`: paletas claro/escuro.
